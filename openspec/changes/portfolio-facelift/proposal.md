## Why

The current portfolio needs a visual refresh to look more premium, modern, and aligned with recent design trends. A "facelift" based on the "MetaNav" aesthetic will provide a sleek, dark-themed experience with vibrant red accents and smooth typography, creating a strong first impression for visitors.

## What Changes

- Complete overhaul of the portfolio's color palette to a dark mode theme with red accent colors (`#c30f1f`).
- Update typography to modern sans-serif fonts (e.g., Inter, Roboto, or similar) matching MetaNav's style.
- Redesign the layout to include a sidebar or topbar navigation similar to MetaNav's `app-shell`.
- Add micro-animations and hover effects for interactivity and a more premium feel.
- Ensure the design system is consistent across all sections (projects, about, contact).

## Capabilities

### New Capabilities
- `visual-design`: Defines the new design tokens, color palette, typography, and core layout components (sidebar, topbar, app shell).

### Modified Capabilities
- `portfolio-layout`: The core layout requirements are changing to adopt the MetaNav-inspired app-shell structure.

## Impact

- **UI/CSS**: Major changes to `index.css` or global styles, introducing new CSS variables for the dark theme.
- **Components**: Structural changes to layout components (Header, Navigation, Main Content Area).
- **No functional changes**: The underlying data and content of the portfolio remain the same, only the presentation is updated.
